PROPERTY TRADER — VOICE LINES TRACKER
======================================
Plain-text list of every voice line category the code knows about, kept
up to date as we add more. One line is picked at random each time a
category is played, so more numbered variations for the same category =
more variety, not required.

*** THIS FILE IS MIRRORED IN TWO PLACES — KEEP BOTH IDENTICAL ***
  1. property-trader-online_1/monopoly-online/public/sounds/voice/  (here)
     — used by the online (server/browser) build.
  2. sounds/voice/  (top-level, next to monopoly-hotseat.html)
     — used by the hotseat build. This is also the folder the owner
     actually drops new recordings into day to day.
Both builds need their OWN copy of every .mp3 (the online build can only
serve files from inside property-trader-online_1/monopoly-online/public/,
it can't reach the top-level folder) — when a new recording gets added
to one, copy it to the other too, and update this tracker in both spots.
Number clips specifically go in a "numbers" subfolder under sounds/voice/
in each location (see the NUMBERS section below) — everything else stays
directly in the parent sounds/voice/ folder.

Status key: [RECORDED]   = files exist in both folders right now, and
                            something in the code actually calls them.
            [SUPERSEDED] = files exist, but no longer called by
                            anything — replaced by a newer line below.
            [NEEDED]     = code expects it, files not added yet.

*** RECURRING GOTCHA: don't let the filename end up as "name.mp3.mp3" ***
This has happened three times now — whatever export/save step is being
used sometimes appends .mp3 on top of a name that already ends in .mp3.
Before calling a batch of new recordings done, glob for "*.mp3.mp3" in
both folders and fix any that show up (the code requests the
single-extension name and will just silently fail to play a
double-extension file, no error, no crash — easy to mistake for "the
line isn't working" instead of a naming mistake).

*** THESE GO IN THEIR OWN SUBFOLDER, NOT LOOSE IN sounds/voice/ ***
  property-trader-online_1/monopoly-online/public/sounds/voice/numbers/
  sounds/voice/numbers/                     (top-level, hotseat's copy)

The minimum set needed to read any number from 1 up through the hundreds
of thousands, via numberToVoiceCategories() in both builds' code: 1-20
individually (English's teens are irregular — "eleven"/"twelve"/
"thirteen" etc. aren't built from smaller words, so there's no way around
one clip each up to 20), the tens words 30/40/.../90 (20 itself is
already in the 1-20 set above), and the two multiplier words "hundred"/
"thousand".

  number-1-1.mp3    "One"          number-11-1.mp3   "Eleven"
  number-2-1.mp3    "Two"          number-12-1.mp3   "Twelve"
  number-3-1.mp3    "Three"        number-13-1.mp3   "Thirteen"
  number-4-1.mp3    "Four"         number-14-1.mp3   "Fourteen"
  number-5-1.mp3    "Five"         number-15-1.mp3   "Fifteen"
  number-6-1.mp3    "Six"          number-16-1.mp3   "Sixteen"
  number-7-1.mp3    "Seven"        number-17-1.mp3   "Seventeen"
  number-8-1.mp3    "Eight"        number-18-1.mp3   "Eighteen"
  number-9-1.mp3    "Nine"         number-19-1.mp3   "Nineteen"

  number-30-1.mp3   "Thirty"       number-70-1.mp3   "Seventy"

Example chains (already verified against these exact sequences in code):
  21     -> Twenty + One                          "Twenty-one"
  150    -> One + Hundred + Fifty                  "One hundred fifty"
  1,500  -> One + Thousand + Five + Hundred        "One thousand five hundred"
  4,999  -> Four + Thousand + Nine + Hundred + Ninety + Nine
  12,345 -> Twelve + Thousand + Three + Hundred + Forty + Five
  20,000 -> Twenty + Thousand                      "Twenty thousand"
234 (verified live in an actual rent payment) -> Two + Hundred + Thirty + Four
Note: no "zero" clip — numberToVoiceCategories(0) returns an empty list
on purpose, so a $0 amount just says nothing rather than needing a word
nobody's recorded yet.


HOW TO ADD MORE VARIATIONS LATER
-----------------------------------
Any category above can have more than one recording — just add
<category>-2.mp3, <category>-3.mp3, etc. (matching the existing
numbering) to BOTH folders, and tell Claude to bump that category's
count in VOICE_LINE_COUNTS in both public/index.html and
monopoly-hotseat.html. No other code changes needed.
